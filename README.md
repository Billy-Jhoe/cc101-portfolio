## Sample Pseudocode: Decimal to Binary
 
```
 START
    INPUT decimal
    
    IF decimal == 0 THEN
        DISPLAY “0”
    ELSE
        SET binary = “”
        WHILE decimal > 0 DO
            SET remainder = decimal MOD 2
            SET binary = remainder + binary
            SET decimal = decimal DIV 2
        ENDWHILE
        DISPLAY binary
    ENDIF
END
```
